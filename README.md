## Agência Nacional de Transportes
Este projeto consiste na análise de um conjunto de dados públicos referente ao setor de transportes no Brasil, visando extrair informações relevantes através do tratamento de dados, fórmulas e recursos visuais.

## 📌 Sobre o Projeto

Para realizar a análise, o conjunto de dados foi obtido diretamente do portal de Dados Abertos do Governo Federal (dados.gov.br). Os dados foram organizados e representados em tabelas estruturadas no Microsoft Excel.

Com base nos dados importados, foram elaboradas duas questões principais para orientar o diagnóstico. Para responder a essas perguntas e apresentar as conclusões, utilizei:

Fórmulas no Excel (com destaque para a função CONT.SE);

Gráficos dinâmicos/visuais para representação dos resultados.

## ❓ Perguntas da Análise

As perguntas elaboradas para estruturar o estudo foram:

Qual a Unidade da Federação (UF) com o maior número de empresas habilitadas?

Quantas empresas possuem adesão ao Decreto nº 1.563/95?

## 📊 PROJETO 01 | REGRESSÃO LINEAR COM PYTHON

📈 Excel, Estatística e Google Colab

Este projeto explora a aplicação de conceitos estatísticos na análise de dados, utilizando o Microsoft Excel e o Python, por meio do Google Colab.

A proposta é trabalhar com gráficos de dispersão e regressão linear simples, identificando relações entre variáveis e analisando tendências por meio de métodos estatísticos.

Além disso, o projeto permite comparar os resultados obtidos em diferentes ferramentas, unindo conhecimentos de estatística, tecnologia e análise de dados.

## 🎯 OBJETIVOS

Organizar e analisar dados no Excel.

Desenvolver gráficos de dispersão para visualizar relações entre variáveis.

Aplicar a regressão linear simples utilizando Python.

Compreender e interpretar resultados estatísticos.

Comparar os resultados obtidos no Excel e no Google Colab.

🛠️ TECNOLOGIAS E FERRAMENTAS

Microsoft Excel: organização e visualização de dados.

Python: aplicação de cálculos e conceitos estatísticos.

Google Colab: ambiente para desenvolvimento e execução dos códigos.

💡 CONHECIMENTOS DESENVOLVIDOS

Estatística aplicada, análise de dados, visualização gráfica, programação em Python e interpretação de resultados.

🚀 RESULTADO

Uma experiência prática que integra ferramentas de análise e programação, fortalecendo conhecimentos em estatística e desenvolvendo habilidades fundamentais para a área de Dados e Business Intelligence.
